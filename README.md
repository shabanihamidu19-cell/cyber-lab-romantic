# CYBER LAB — Romantic Generative Art

A soft, elegant generative art experience blending cyber aesthetics with romantic & cosmic scenes.

## Features

- **Generative** – flowing neon curves
- **DNA** – double helix with soft glow
- **Rose** – blooming rose with falling petals, butterflies & fireflies
- **Love Mode** – rose + heartbeat glow + particles
- **Cosmic** – stars, moon, aurora & soft galaxy
- **Matrix** – classic rain with a romantic twist
- **Auto** – cycles through all scenes

### Interactions
- Type a name → personal message appears
- Click the rose → petals burst + message
- Ambient sound (optional) with mute button

## Deploy

This is a pure static site. Host it on:

- **GitHub Pages** (recommended)
- Netlify / Vercel / Cloudflare Pages
- Any static host

Just open `index.html` or push to a repo with Pages enabled.

## Local

```bash
# any static server
npx serve .
# or
python -m http.server 8080
```
